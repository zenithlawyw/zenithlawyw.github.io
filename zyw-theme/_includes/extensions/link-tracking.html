{%- comment -%} link-tracking.html ================== Configure-once, apply-all link tracking extension. Behaviour: 1. On DOMContentLoaded: scan every in the page. Outbound links (different origin) receive UTM query parameters when site.link_tracking.outbound_utm is configured, unless those parameters are already present in the target URL. 2. On delegated click: fire a GA4 / GTM dataLayer event for every outbound click (and optionally internal clicks). 3. DNT: honours the Do Not Track header when site.enableDNT is "true". Configuration (docs/_config.yml): link_tracking: outbound_utm: source: "zenithlaw.com" medium: "referral" campaign: "post-link" content: "" # optional term: "" # optional ga4_events: true # fire gtag / dataLayer events (default: true) track_internal: false # also fire events for internal links (default: false) exclude_patterns: # regex strings; matched links are skipped entirely - "^mailto:" - "^tel:" - "^javascript:" {%- endcomment -%} {%- assign _lt = site.link_tracking -%} {%- assign _lt_utm = _lt.outbound_utm | default: null -%} {%- assign _lt_ga4 = _lt.ga4_events | default: true -%} {%- assign _lt_int = _lt.track_internal | default: false -%} {%- assign _lt_excl = _lt.exclude_patterns | default: null -%}
