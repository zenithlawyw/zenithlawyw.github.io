## Career Arc

A career built through deliberate pivots across domains, each deepening rather than replacing what came before. Starting in telecommunications and gaming infrastructure, then moving through financial technology within large international banks, then building and running an accredited training organisation, then leading technical delivery for a regulated healthcare platform, and now working hands-on on industrial IoT platforms and edge network simulation systems.

Data architecture runs as a consistent thread across these roles, applied within the regulatory environment of each domain. Security, compliance, and governance are considered from the outset of any engagement. This combination supports work where explanations, auditability, and compliance are important, and where engineering decisions intersect with legal and regulatory constraints.

## Engineering Practice

### Strategic Leadership

He operates at a director or vice president level of influence without managing people directly. He guides company-wide technical direction through credibility, mentorship, and relationships rather than direct control, and explains complex technical realities to executive management in business and financial terms. He acts as an autonomous troubleshooter and high-level escalation point for mission-critical technical challenges, while remaining hands-on across the stack.

### Full-Stack Scope

Go, Python, Java, TypeScript, and C#/.NET across frontend (Vue 3, Nuxt 4, Quasar, React 19, Next.js 15), backend (.NET 8, Spring Boot 3.x, FastAPI, Node.js), infrastructure (Kubernetes/k3s, Terraform, Helm, Azure, DigitalOcean), protocols (protobuf, MQTT, RabbitMQ, gRPC, TCP sockets), and databases (PostgreSQL, SQL Server, MongoDB). The stack is treated as a whole rather than in layers, from binary protocol debugging at the wire level through cloud infrastructure provisioning to accessible and performant user interfaces.

### AI-Augmented Development

Building and governing AI-augmented engineering tooling forms part of current daily practice. Develops custom GitHub Copilot agents, instruction files, and MCP server integrations that encode domain knowledge for AI-assisted engineering. Maintains governance ecosystems enforcing code quality and security posture when AI tools are in the development loop. Deploys LLM inference infrastructure (vLLM, Ollama) and builds autonomous multi-agent orchestration systems for code analysis and deployment validation.

### Testing & Quality

Unit testing across Vitest, Go testing, pytest, xUnit, JUnit. E2E testing with Playwright and Cypress. WCAG 2.2 AA accessibility compliance (axe-core audits). Performance validation for virtual scroll rendering and large dataset handling.
